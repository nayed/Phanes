Vim mode — four states

The editor pane and status bar of the main window in Gruvbox Light. The mode pill, cursor shape and command line are all that change; mode colors come from the active colorscheme.

Normal

Block cursor on the character, in the theme’s link color. Keys typed so far (here 2d, waiting for a motion) show right after the pill.
